# 人物订阅（PersonSubscribe）

搜索 TMDb 订阅演员/导演（头像 + 代表作人工确认，不会误订同名人物），周期扫描其
参演/执导作品，按策略过滤后自动创建 MoviePilot 订阅；未上映作品保持待映跟踪，
上映后自动补订。

## 核心特性

- **人物驱动**：以 TMDb Person ID 订阅人物，身份持久化，绝不因同名搜索结果漂移。
  添加时展示头像、原名、职业与代表作，由用户确认。
- **演员与导演**：作品范围可选参演、执导或两者（导演取 crew 中 job=Director 的作品）。
- **策略过滤**（全局默认策略 + 单人物独立策略）：
  - 媒体类型（电影/电视剧）、起始年份
  - 题材必须包含 / 排除（TMDb 无"综艺"题材，综艺类由真人秀+脱口秀代表，可一并排除）
  - 评分下限 × 最低投票数组合门禁（投票不足不启用评分门槛）
  - 仅主演/主创（媒体演员表前 3 位）
  - 要求中文译名（可选，默认关闭）
- **状态机**：待上映 → 上映自动翻转补订；库内已有或订阅完成 → 已入库（事件收口）；
  用户删除未完成订阅 → 已忽略（可在页面恢复）。
- **共享目标**：多个人物命中同一作品只创建一个订阅，删除人物不影响其他人物的追踪。
- **管理界面**（Vue 联邦 UI）：人物卡片墙、作品追踪列表、暂停/恢复、手动刷新
  （单人/全部）、独立策略编辑、忽略/恢复单个作品。

## 与 ETKvNext 演员订阅的关系

行为移植自 ETKvNext `modules/subscription/actor.py` 的成熟实现。有意差异：
作品目标按整片/整剧粒度（MoviePilot 订阅原生管理缺集与追更），不拆季；
「需求层」由 MoviePilot 订阅本身承担，订阅完成事件直接收口。

## 使用

1. 在 MoviePilot 插件市场添加本仓库地址后安装「人物订阅」。
2. 启用插件，按需调整执行周期与默认策略。
3. 打开插件详情页 → 「添加人物」→ 搜索并确认订阅。
4. 等待扫描完成（新人物添加后会立即扫描一次），或点击「全部刷新」。

## 说明

- 人物作品来自 TMDb `combined_credits`（一次请求含参演+执导全量作品），
  避开链层 `person_credits` 的本地分页重复请求。
- TMDb 语言默认 `zh-CN`，可在设置中调整。
- 本插件只创建订阅，不直接下载；下载、整理、入库由 MoviePilot 原生流程完成。
